# Infinite Repel Mod for Gen2Recomp

Easily toggle wild Pokemom encounters from the start menu.

## Installation
1. Go to the [Releases](https://github.com/hunter6571/infinite_repel_gen2/releases) page and download the latest `Infinite_Repel.zip` under **Assets**.
3. Place the `.zip` file into your **Gen2Recomp** `mods` directory.
4. Launch **Gen2Recomp** and ensure the mod is enabled in the mod manager.
